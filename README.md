# WARNONAMI

**A Global Turn-Based Grand Strategy Game for Android**

WARNONAMI is an Android strategy game developed with Java.

## Planned Features

- Seven supported languages
- Countries and provinces around the world
- Historical scenarios
- Economic management
- Diplomacy and international relations
- Turn-based gameplay
- Single-player and multiplayer modes
- Custom maps and scenarios

## Technology

- Programming Language: Java
- Platform: Android
- Build System: Gradle
- Repository: GitHub

## Project Status

Currently in the initial development stage.

More features will be added gradually.
